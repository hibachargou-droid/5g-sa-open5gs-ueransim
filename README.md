# Réseau 5G Standalone simulé : Open5GS + UERANSIM

## Objectif
Déployer un réseau 5G SA simulé (cœur Open5GS, gNB et UE UERANSIM), valider
l'enregistrement de l'UE et la session PDU, puis analyser les échanges
NGAP/NAS sous Wireshark.
